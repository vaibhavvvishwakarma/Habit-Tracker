# Stride – Habit Tracker (UI/UX Project)

A mobile habit tracker designed for people who get overwhelmed by feature-heavy apps. Five screens, one accent color, and a small reusable component system.

## Links
- **Figma file:** https://www.figma.com/design/YkLGvYSsc9EIYOXHUYp5FH
- **Figma prototype:** _paste your "Share prototype" link here_
- **Web prototype:** open `prototype/index.html` in a browser (tap habits to complete them, add a habit, switch tabs, toggle dark theme)

## Screens
1. **Today:** week strip, progress ring, habit list with tap-to-complete
2. **Add habit:** name, icon, color, repeat schedule, reminder
3. **Habit detail:** current streak, best streak, 5-week heatmap
4. **Stats:** weekly bar chart, overall completion, best habit
5. **Profile:** theme and notification settings

Add your exported screens to the `screenshots/` folder and reference them here.

- Frame: 390 x 844 (iPhone 14), 8px spacing grid, 16px card radius
- Type scale: Title 28, Heading 20, Body 16, Caption 13
- Components: Habit row (Default/Done), Progress ring, Tab bar, Primary button
